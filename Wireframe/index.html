Web Development Basics

A short guide to three things every new developer needs to know: READMEs, wireframes, and Git branches.

What is the purpose of a README file?

A README is the first file people read in a project. It explains what the project is, how to set it up and use it, and where to find more help.

What is the purpose of a wireframe?

A wireframe is a simple line drawing of a page layout. It shows where things go and what they do, before any code is written.

What is a branch in Git?

A branch is a separate line of work in a project. You can change things safely on a branch without affecting the main version, then merge it back when you are ready.
